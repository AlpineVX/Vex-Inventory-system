# Code of Conduct

## Our Pledge

Contributors, coaches, mentors, and students working on **VEX Robotics Team 654 — Parts Inventory** pledge to keep collaboration welcoming, constructive, and aligned with the **VEX Robotics Code of Conduct** and Gracious Professionalism.

## Expected Behavior

- Communicate respectfully in issues, pull requests, and code reviews.
- Give clear reproduction steps when reporting bugs during shop days or tournaments.
- Respect student privacy and never commit personal emails, school IDs, or private Google Apps Script deployment links to the repository.
- Focus feedback on code quality, usability for students, and safety for club hardware.

## Unacceptable Behavior

- Harassment, personal attacks, or derogatory remarks toward any student, mentor, or contributor.
- Intentionally disabling safety checks, SSRF proxy protections, or admin access boundaries.
- Publishing private team credentials or unredacted spreadsheet URLs.

## Reporting

Please report concerns privately to a Lake Travis VEX Robotics Club 654 coach, lead mentor, or repository maintainer so issues can be addressed promptly.
